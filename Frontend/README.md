# CAVE-Flood Frontend — Earth Observation Segmentation Web Application

A modern, high-precision scientific web dashboard for satellite flood inundation detection and semantic segmentation.

## 🚀 Running the Frontend

```powershell
# Navigate into Frontend directory
cd Frontend

# Install dependencies (first time only)
npm install

# Start the Vite development server
npm run dev
```

Application will be available at:
`http://localhost:5173`

## 🛠️ Architecture & Technologies

- **React 18** + **Vite 5**
- **Vanilla CSS** with **Scientific Geospatial Precision** design system tokens
- **React Router v6** for multi-view client routing
- **Axios** for REST API integration
- **Lucide React** for technical iconography
- **Interactive Before/After Slider** for direct optical vs segmentation comparison

## 🌐 Routes

- `/` — Platform Overview, capabilities, and architecture summaries
- `/analyze` — Satellite Raster Analysis workspace (Drag-and-drop, metadata inspector, inference execution, quantitative telemetry)
- `/compare` — Multi-model comparison matrix
- `/models` — Architectural formulations and cryptographic checkpoint ledger
- `/results/:id` — Direct result record inspector
